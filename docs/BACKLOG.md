# Plan Wydań (MVP i v1.0) — SDA MOST

## MVP (v0.1) - Cel: "MOST widzi kalendarz i loguje się"
**Foundation & Structure:**
- [ ] Zaloguj użytkownika (JWT / Sesja).
- [ ] Wyświetl profil użytkownika.
- [ ] Wyświetl drzewo MOST-u i liderów (`OrganizationUnit`, `LeadershipAssignment`).

**Activities Core:**
- [ ] Stwórz inicjatywę (`Initiative`).
- [ ] Stwórz wydarzenie z datą (`Occurrence`).
- [ ] Kalendarz: Generowanie spotkań wg reguł (np. Lectio co tydzień).

## Wersja v1.0 - Cel: "Pełne interakcje, wolontariat i punkty"
**Participation:**
- [ ] Zapisz się na wydarzenie (`Enrollment`).
- [ ] Odwołaj zapis (przed startem).
- [ ] Wyświetl listę uczestników (dla organizatorów).
- [ ] Sprawdź obecność (`Attendance`).

**Engagement & Communication:**
- [ ] Nalicz punkty (obecność).
- [ ] Wyświetl historię transakcji punktowych.
- [ ] Egzekwuj miesięczne limity punktów.
- [ ] Preferencje powiadomień (opt-in).
