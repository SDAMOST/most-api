| Termin | Znaczenie | Przykłady użycia |
|---|---|---|
| **MOST** | Wspólnota SDA MOST | „Jestem w MOST.” |
| **Mostowiak** | Członek wspólnoty MOST | „Jan jest Mostowiakiem.” |
| **Kadra** | Sekstet / Septet oraz przęsłowi | „Kadra ustala plan działania MOST-u.” |
| **Sekstet / Septet** | Najwyższe grono zarządzające MOST-em; nazwa zależna od liczby osób | „Sekstet zweryfikował konto.” |
| **Przęsło** | Główny dział organizacyjny MOST-u | „Przęsło Turystyczne.” |
| **Przęsłowy** | Osoba odpowiedzialna za przęsło | „Jan jest przęsłowym Turystycznego.” |
| **Podprzęsło** | Jednostka organizacyjna należąca do przęsła | „Lectio jest podprzęsłem.” |
| **Podprzęsłowy** | Osoba odpowiedzialna za podprzęsło | „Jan jest podprzęsłowym Lectio.” |
| **Seria wydarzeń** | Zbiór powiązanych wydarzeń; seria jest przypisana do elementu konstrukcji MOST-u | „Seria Obiady”, „Seria Majówka” |
| **Wydarzenie** | Konkretne zdarzenie należące do Serii wydarzeń, odbywające się w określonym czasie | „Obiad 12 września jest wydarzeniem.” |
| **Zapis** | Zgłoszenie udziału w wydarzeniu | „Jan zapisał się na obiad.” |
| **Post** | Publiczna informacja publikowana w aplikacji | „Kadra opublikowała post.” |
